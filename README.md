# MineKingdom

Minecraft 1.20.1 / Forge 47.2.0 / Java 17 기반 왕국 건설 모드.

## 개발 환경

```bash
./gradlew runClient   # 클라이언트 실행
./gradlew build       # 모드 jar 빌드
```

Java 17이 필요합니다. `JAVA_HOME`이 17을 가리키지 않는다면 다음처럼 지정합니다.

```bash
JAVA_HOME=/path/to/jdk-17 ./gradlew runClient
```

## 현재 구현: 시민(Citizen)

크리에이티브 "생성 알" 탭의 **시민 생성 알**로 소환합니다.

- 플레이어 모델을 사용하며 소환 시 남/녀가 무작위로 결정됩니다.
  - 남성: 클래식(스티브) 모델 + 스티브 스킨
  - 여성: 슬림(알렉스) 모델 + 알렉스 스킨
- 배회, 문 열기, 물에 뜨기, 플레이어 쳐다보기 AI를 가지며 길찾기로 이동합니다.
- 걷는 속도는 플레이어와 비슷한 초당 약 4.2블록입니다. 지상 이동 속도는 특성값에 비례하지
  않고, 실측상 `42.6 × (이동속도 특성 × goal 속도 계수)²` blocks/s에 가깝습니다.
  (0.25 → 2.66, 0.35 → 5.23, 0.45 → 8.55 b/s 실측)
- 멀리 떨어져도 디스폰되지 않습니다.

### 중립 몹

도망치지 않으며, 공격받으면 반격합니다. 한 번 화가 나면 20~39초간 유지되고 그 상태는
저장됩니다. 근처의 다른 시민도 함께 반응합니다. 기본 공격력은 2이며, 무기를 들고 있으면
그 무기의 공격력이 더해집니다.

### 인벤토리

주민과 동일하게 8칸 인벤토리를 가집니다. 선택된 슬롯의 아이템이 오른손에 복사되어
플레이어처럼 들고 있는 형태로 렌더링됩니다. 곡괭이는 곡괭이 형태로, 블록은 블록 형태로
각 아이템의 고유 모델대로 표시됩니다.

바닥에 떨어진 아이템을 밟고 지나가면 인벤토리에 담습니다. 아이템 쪽으로 일부러 이동하지는
않으며, 인벤토리가 가득 차면 줍지 않습니다. (`mobGriefing` 게임규칙을 따릅니다.)

### 채굴

시민에게 채굴을 시키면 다음 규칙으로 움직입니다.

1. 반경 6블록(수직 3블록) 안에서 **드러난** 돌·광석을 다음 순서로 고릅니다.
   ① 광석 → ② 캐도 설 자리가 줄지 않는 블록 → ③ 나머지. 같은 순위 안에서는 가까운 순입니다.
   ②는 블록을 없앴을 때 서 있을 수 있는 위치가 그 블록·위·아래 세 칸에서만 바뀐다는 점을
   이용해 값싸게 판정하며, 발판을 스스로 파내는 선택을 뒤로 미룹니다(가까운 비광석 24개까지).
   단, 실제로 **눈에 보이는** 블록만 대상입니다. 다른 블록에 가려져 있으면 캘 수 없고,
   보이는 위치까지 걸어가야 합니다. 채굴 사거리는 3블록입니다.
2. 자기 발밑 블록과 자기가 서 있는 기둥은 캐지 않습니다.
3. 캤을 때 액체가 새거나 위의 모래·자갈이 떨어질 블록은 캐지 않습니다.
4. 이동은 단차 ±1, 머리 공간 2칸인 걸음만 사용합니다. 모든 걸음이 역방향으로도 걸을 수
   있으므로 항상 되돌아올 수 있습니다. 이 걸음으로 닿을 수 없는 블록은 대상에서 제외됩니다.
5. 캔 뒤에 최근 지나온 발판으로 되돌아갈 수 없게 되는 블록은 캐지 않습니다. 규칙 4는 그
   순간의 지형만 보지만 채굴은 지형을 바꾸므로, 최근 서 있던 위치를 기억해 두고 해당 블록을
   제거한 가정 하에 다시 경로를 확인합니다.
6. 주변에 캘 것이 없으면 24블록까지 성기게 훑어 광맥을 찾아 이동한 뒤 다시 탐색합니다.
   그래도 없을 때만 채굴을 멈춥니다.

천장에 막혀 올라갈 수 없으면 머리 위 블록을 캐서 뚫습니다. 캘 수도 쌓을 수도 없어 정말로
갇힌 경우에는 조용히 멈추지 않고 서버 로그와 `/ctest mining report`의 `stuck` 항목으로
드러납니다.

그럼에도 지형 변화로 갇힌 경우, 인벤토리의 블록을 발밑에 쌓아 올라옵니다(`mobGriefing` 준수).
쌓을 블록이 없으면 주변 돌을 캐서 그 드롭을 주워 보충합니다.

현재는 곡괭이 없이도 캘 수 있으며, 채굴 속도는 `CitizenEntity#getDestroyProgressPerTick`
한 곳에서 결정됩니다. 곡괭이를 도입할 때 이 메서드만 교체하면 됩니다.

## 명령어

`/ctest`는 시민을 손으로 부려 보기 위한 테스트 명령어입니다 (권한 레벨 2 필요).

| 명령어 | 동작 |
| --- | --- |
| `/ctest select [범위] [n]` | 명령 위치 기준 범위 안의 가까운 시민 n명을 선택 (기본 범위 16, n 제한 없음) |
| `/ctest mining start` | 선택한 시민이 채굴 시작 |
| `/ctest mining stop` | 선택한 시민이 채굴 중지 |
| `/ctest mining report` | 시민별 채굴한 블록 수와 합계 출력 (노는 시민 확인용) |
| `/ctest mining reset` | 채굴 카운터 초기화 |
| `/ctest home set` | 선택한 시민의 현위치를 복귀지점으로 기록 |
| `/ctest home return` | 선택한 시민을 복귀지점으로 복귀시킴 |
| `/ctest home report` | 선택한 시민의 복귀지점까지 거리와 도착 여부 집계 |
| `/ctest debug` | 선택한 시민의 현재 작업과 실행 중인 AI goal 출력 |

복귀는 길찾기로만 이뤄지며 순간이동은 사용하지 않습니다. 도착하거나 포기하면 서버 로그에
결과가 한 줄씩 남고, 출발 당시 거리가 함께 기록되어 실제로 이동했는지 로그만으로 확인할 수
있습니다. 도착 판정 기준은 1.5블록(`CitizenEntity.RETURN_ARRIVAL_DISTANCE`)입니다.

명령어는 시민을 고르고 작업을 바꾸는 일만 합니다. 동작 자체는 전부 엔티티에 있으므로,
나중에 직업 시스템이나 건물에서 부를 때는 `CitizenEntity#setTask(CitizenTask)`를 직접
호출하면 됩니다. 선택 기능이 필요 없다면 `CitizenSelectionManager`를 거치지 않아도 됩니다.

| 조작 | 동작 |
| --- | --- |
| 아이템을 들고 우클릭 | 해당 아이템을 인벤토리에 넣고 그 아이템을 들게 함 |
| 맨손으로 우클릭 | 다음으로 채워진 슬롯으로 전환 (들고 있는 아이템 변경) |
| 웅크린 채 맨손으로 우클릭 | 인벤토리 내용물을 전부 돌려받음 |

인벤토리 상태는 액션바에 표시되며, 시민이 죽으면 소지품을 전부 떨어뜨립니다.
